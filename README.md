# Portafolio de Heberto Barrera

Sitio estático publicado con GitHub Pages en https://betobeckermancie.github.io

## Contenido

- `index.html`: página completa (HTML, CSS y JavaScript en un solo archivo, sin dependencias de compilación).
- `assets/pecsa/`: capturas del proyecto de Casas Pecsa (Azure Databricks y Power BI).

## Cómo editarlo

1. Edita `index.html` directamente en GitHub (ícono del lápiz) o en tu computadora.
2. Guarda con un commit en la rama `main`.
3. GitHub Pages publica el cambio en uno o dos minutos.

Para agregar un proyecto nuevo, copia uno de los bloques `<article class="case">` dentro de la sección `#proyectos` y cambia el texto. Las imágenes van en `assets/<nombre-del-proyecto>/`.
